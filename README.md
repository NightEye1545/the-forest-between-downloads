# The Forest Between — Gameplay Demo

**Your hands are the magic.**

Protect Luma, a little light in a dangerous forest, by conjuring spells and combining elements in a controller-free VR adventure.

This standalone gameplay demo introduces the hands-only controls, elemental combinations and encounters of **The Forest Between**. The full story-driven adventure is still in development.

## Installation

This is a sideloaded APK download. You will need a computer and a headset configured for developer access.

1. Download `TheForestBetween-Demo-Release.apk` using the link above.
2. Connect your headset to your computer and authorize its developer/USB connection.
3. Install the APK using Meta VR Developer Hub. Follow [Meta's official APK installation guide](https://developers.meta.com/vr/documentation/unity/ts-mqdh-deploy-build/).
4. Open **The Forest Between** from the headset's **Unknown Sources** apps list and select **Play Demo**.

If you already have a differently signed development build installed, Android may block an in-place update. Back up any app data before replacing that build.

## Playing

Play seated or stationary, with room to move your hands safely. Luma demonstrates the gestures before each practice step. Keep your hands visible in front of you and take your time. Look down for the journal to pause.

The demo has been tested on Quest 3 with its normal view and with a simulated 70° horizontal × 66° vertical field of view. This is a Quest simulation, not a claim of testing on Meta VR Glasses hardware.
